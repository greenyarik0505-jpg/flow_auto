# Google Flow Studio Plugin for AI Agents

Плагин для **Google Antigravity**, **Claude Code** и **OpenAI Codex / Cursor**.
Обеспечивает сквозную автоматизацию генерации видео (Veo 3.1, Gemini Omni) и фото (Imagen 4) через Google Flow с поддержкой пула из 1..34+ аккаунтов и умной авто-ротацией квот.

## Возможности

- 🎬 **Генерация видео (Veo 3.1 & Gemini Omni):** длительность 4-10 сек, соотношение 16:9 и 9:16, фотореализм и плавная кинематографичная динамика.
- 🎨 **Генерация фото (Imagen 4 / Nano Banana):** высокое разрешение, соотношения 16:9, 9:16, 1:1, 4:3, 3:4.
- 🔄 **Авто-ротация по 34+ аккаунтам:** при исчерпании суточных кредитов (HTTP 429) генератор автоматически переходит к следующему свободному аккаунту.
- 🎯 **Точечный выбор профиля:** можно запустить генерацию с конкретного аккаунта (например, `2`, `10` или `34`).
- 🛡️ **Изолированные контейнеры:** каждый аккаунт сохраняется в отдельном persistent-профиле Chrome со своей базой SQLite — исключен риск блокировок со стороны Google.
- 🔌 **Встроенный MCP сервер:** 20 нативных инструментов для ИИ (вызов функций `gflow_generate_video`, `gflow_generate_image`, проверка квот и статуса).

## Быстрый старт (CLI)

```powershell
# Посмотреть все аккаунты и статус Flow:
.\list_profiles.bat

# Авторизовать нужный аккаунт (например, 2):
.\login.bat 2

# Сгенерировать видео с авто-ротацией по всем аккаунтам:
.\generate.bat "Красивый водопад в горах на закате" --profile auto

# Сгенерировать фото через конкретный аккаунт:
.\generate_image.bat 2 "Киберпанк город под неоновым дождем"

# Сбросить кэш лимитов:
.\generate.bat --reset-limits
```
