# Flow Auto Sync (Расширение Chrome)

Расширение для автоматического захвата авторизации Google Flow для **flow_auto**.

## Как подключить (1 раз):
1. Откройте в Chrome: `chrome://extensions`
2. Включите переключатель **Режим разработчика** (вверху справа).
3. Нажмите **Загрузить распакованное расширение** (вверху слева) и выберите эту папку:
   `d:\flow_auto\flow_extension`

## Как это работает:
1. Запустите: `.\login.bat --all` (или `.\login.bat <номер>`).
2. Скрипт открывает каждый профиль по очереди.
3. Как только вкладка `flow.google.com` загружается — расширение само отправляет куки в `login.bat`, сессия сохраняется, и скрипт мгновенно переходит к следующему профилю!
