# Flow Auto Helper (Chrome Расширение)

Простое расширение для Google Chrome, позволяющее в 1 клик скопировать токен авторизации Google Flow (`__Secure-next-auth.session-token`) в буфер обмена.

## Как установить (за 10 секунд):
1. Откройте в Google Chrome страницу: `chrome://extensions`
2. В правом верхнем углу включите переключатель **Режим разработчика** (Developer mode).
3. Нажмите кнопку **Загрузить распакованное расширение** (Load unpacked) в верхнем левом углу.
4. Выберите эту папку: `d:\flow_auto\flow_extension`.

## Как использовать:
1. Запустите `.\login.bat <номер_профиля>`.
2. В открывшейся вкладке Chrome с `flow.google.com` нажмите на значок расширения.
3. Нажмите кнопку **📋 Скопировать токен Flow**.
4. В окне `login.bat` нажмите Enter — токен сохранится мгновенно!
